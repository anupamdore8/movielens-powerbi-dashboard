# MovieLens Power BI Dashboard (UT Austin Data Analytics Essentials)

## Project Overview
This project analyzes classic movie ratings using the MovieLens dataset and presents insights through an interactive Power BI dashboard. It was completed as part of the UT Austin Data Analytics Essentials certification.

## Objectives
- Understand movie rating patterns over time
- Identify top-rated movies and genres
- Explore user behavior and rating distributions

## Tools & Skills (Tags)
- Power BI
- DAX
- Data Modeling
- Data Visualization
- Data Cleaning
- Exploratory Data Analysis (EDA)

## Key Features
- Interactive filters by genre, year, and rating
- KPIs for average rating, number of ratings, and top movies
- Drill-through pages for detailed movie-level analysis
